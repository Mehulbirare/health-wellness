## 📖 Overview

**Prakruti** is a sophisticated wellness platform that bridges the gap between ancient Ayurvedic wisdom and contemporary health tracking. By analyzing your unique physical and mental traits, Prakruti identifies your primary and secondary **Doshas**—Vata, Pitta, and Kapha—to provide a personalized roadmap for diet, lifestyle, and mental clarity.

### Why Prakruti?
Ayurveda teaches that health is the state of being established in one's own natural self. When our unique ratio of elements is in harmony, we experience effortless vitality. Prakruti helps you find that equilibrium.

## 🛠️ Technology Stack

### Frontend
- **React.js**: Powering the interactive UI components.
- **Material UI (MUI)**: Providing a premium, modern design language.
- **Framer Motion**: Enabling fluid animations and transitions.
- **Chart.js**: Visualizing complex Dosha data elegantly.

### Backend
- **Node.js & Express**: High-performance server-side architecture.
- **MongoDB**: Flexible document-based storage for user profiles and assessments.
- **JWT**: Robust security and authentication.
- **Express Validator**: Ensuring data integrity across all endpoints.

## 🚀 Getting Started

### Prerequisites
- **Node.js** (v16+)
- **NPM** or **Yarn**
- **MongoDB** (Local or Atlas)

### Installation

1. **Clone the Repository**
   ```bash
   git clone https://github.com/MehulBirare/ayurvedic-prakruti-assessment.git
   cd ayurvedic-prakruti-assessment
   ```

2. **Smart Install**
   ```bash
   npm run install-all
   ```

3. **Configure Environment**
   Create a `.env` file in the root directory:
   ```env
   MONGO_URI=your_mongodb_connection_string
   JWT_SECRET=your_super_secret_key
   PORT=5001
   ```

4. **Launch Development Server**
   ```bash
   npm run dev
   ```
